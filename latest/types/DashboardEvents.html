    "dashboard.BOT_MESSAGE": { id: string; message: string; room_id: number }

    The user sent a chat bot command. (Service.Team with ServiceOptions.bot only)

    The message is not posted to the room. Answer within 30 seconds with Dashboard.replyToBotMessage.

    Type Declaration

    • room_id: number

      The chat room id, as in DashboardEvents."dashboard.ROOM_LIST".

    dashboard.BOT_MESSAGE_REJECTED

    "dashboard.BOT_MESSAGE_REJECTED": {
        id: string;
        reason: "INVALID ID" | "INVALID SENDER" | "OLD MESSAGE";
    }

    A reply sent with Dashboard.replyToBotMessage was not posted.

    Type Declaration

    • id: string

      The message id.

    • reason: "INVALID ID" | "INVALID SENDER" | "OLD MESSAGE"

      Why the reply was not posted:

      • INVALID ID: no message has this id, or it was already answered.
      • INVALID SENDER: a different user is now signed in.
      • OLD MESSAGE: more than 30 seconds have passed since the message was sent.
